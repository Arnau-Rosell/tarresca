# Tárrega y Escaned

Website for the artist duo Javier Tárrega and Inés Escaned. It is plain HTML and
CSS with no JavaScript, and each work has its own page.

## Structure

```
content/obra/NN-slug.md   One file per work: front matter + text (Spanish)
docs/                     The published site (GitHub Pages serves this folder)
  css/style.css           Hand-written stylesheet (edit directly)
  fonts/                  Self-hosted Newsreader + Schibsted Grotesk (OFL)
  img/<slug>/             Photos, each in two sizes: NN-900.jpg and NN-1800.jpg
  index.html, obra/, contacto/, 404.html   Generated by build.py — don't edit
build.py                  Generates the HTML from content/ (standard library only)
```

## Editing

1. Change a text in `content/obra/*.md` (or the CSS in `docs/css/style.css`).
2. Run `python3 build.py`.
3. Preview with `python3 -m http.server -d docs` at http://localhost:8000.

### Content file format

```
---
title: La puerta roja
year: 2023                  # groups the work on the index page
date: 2023                  # shown when it differs from the year (e.g. "1984–2024")
cover: cover.jpg            # thumbnail on the index page
media:                      # in display order; "video" marks where video_url goes
  - video
  - 01.jpg
dimensions: 250 x 125 x 80 000 cm
materials:
  - Madera
  - Pintura
thanks: Cris, Tote, vecinos de Casais y Cevide
photos: Sara Mateu          # optional
video_url: https://player.vimeo.com/video/…   # optional embed URL
---

Paragraphs separated by blank lines. Single line breaks are kept.
*italic*, **bold**. Short multi-line paragraphs are set as verse.
```

The numeric prefix of the file name sets the order of the works.

### Adding a photo

Export a JPEG in two sizes (longest side 1800 px and 900 px), for example on macOS:

```sh
sips -s format jpeg -s formatOptions 78 -Z 1800 photo.jpg --out docs/img/<slug>/09-1800.jpg
sips -s format jpeg -s formatOptions 78 -Z 900  photo.jpg --out docs/img/<slug>/09-900.jpg
```

Then add `- 09.jpg` to the `media` list and rebuild.

## Design rules

- Warm paper background (`#f3ede4`) and warm ink (`#2a241f`). No pure black or white.
- Body text contrast is at least 4.5:1. The tokens are documented in `style.css`.
- No cards. Works sit directly on the paper, separated by whitespace and hairlines.
- Hover effects change colour only, run in under 200 ms with ease-out, and only
  apply on devices that can hover. Layout never animates, and reduced motion is
  respected.

## Publishing

In the GitHub repo settings, go to Pages and choose *Deploy from a branch*, then
`main` / `/docs`.
`404.html` uses root-relative links, so it works best with a custom domain.
